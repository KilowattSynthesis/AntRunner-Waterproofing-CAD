# AntRunner Waterproofing CAD

Waterproofing the AntRunner antenna rotator (3D printed frame to hold waterproof fabric)

## Bill of Materials

- 1x of each of the 3 3d printed components (base plate, clamp plate, topper plate)
- Waterproof fabric
    - v1: 3 layers thick, so 170cm (circumference x3) by 100cm (height)
- 4x M5x50mm bolt
- 12x M5 nuts
- 1x AntRunner rotator
